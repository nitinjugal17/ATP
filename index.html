Stages 1–3: Recon & Scope Gate

Headless Chromium spiders the target while NIST scanner fingerprinters backend CVEs. The Scope Gate pauses execution, allowing the QA Lead to inspect discovered routes and token estimations before authoring begins.

Stage 4: Sanitization & Inference

Dynamic IDs and session tokens are stripped from DOMs (saving 40% VRAM). The hardware governor allocates 100% CUDA VRAM, streaming tokens at 88 tok/s with an O(1) circular repetition loop breaker.

Stages 5–6: AST Heal & Pabot

Python scripts pass through ast.parse(). Failing locators are dynamically re-prompted and healed before Pabot executes the suites across 4 CPU cores, compiling into interactive Allure reports.

07 Architectural Trade-Offs: Cloud LLMs vs. Local Sovereign ATP & DevOps Operational Cost

An objective comparison of model capabilities, data security, and true operations/maintenance burdens.

Cloud LLM APIs (OpenAI / Anthropic)

Zero Server Hardware
Advantages (Pros):
  • Immediate access to 200B+ parameter frontier intelligence (Claude 3.7 Sonnet).
  • Zero hardware procurement, server rack space, or physical maintenance.
  • Instant elasticity: Can burst from 1 request to 100 parallel requests instantly.
  • No GPU driver patching or Linux CUDA kernel management.
Disadvantages & Hidden Costs (Cons):
  • Critical Data Exposure: Error dumps, staging JWT tokens, and database schemas leave the company perimeter (Compliance blocker).
  • Rate Limit Bottlenecks: Hard Tier-1 limits (30k TPM) cause HTTP 429 throttling and pipeline-stalling backoff sleeps.
  • Continuous OpEx Bleed: Testing costs scale linearly with test suite size and run frequency.

Sovereign On-Premises ATP Rig

Dedicated Hardware Asset
Advantages (Pros):
  • Absolute Sovereignty: Zero bytes leave the host. 100% air-gap compliant (ASPICE, ISO 26262, SOC 2, HIPAA).
  • Predictable CapEx: Fixed one-time investment; runs 24/7 at zero marginal token cost.
  • Deterministic Latency: Local CUDA VRAM eliminates network serialization and API gateway queues.
  • Integrated Multi-Discipline Stack: UI, API, Load, BDD, and AST Healing out-of-the-box.
Disadvantages & Maintenance (Cons):
  • Initial Hardware Outlay: Requires upfront server budget ($3,600 to $8,500).
  • Platform Management: Internal DevOps must maintain Linux OS, Docker daemon, and NVIDIA container drivers.
  • Facility Demands: Requires ~800W–1200W electrical and cooling capacity for dual-GPU rigs.

from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

@allure.epic("Commerce Checkout Journey")
@allure.story("TC-UI-08: Promo Code Discount & Grand Total Verification")
@allure.severity(allure.severity_level.CRITICAL)
def test_coupon_application_and_hydration_sla():
    """[ASPICE Trace: REQ-SYS-COMM-014] Asserts coupon entry recalculates subtotal within SLA."""
    driver = webdriver.Chrome()
    wait = WebDriverWait(driver, 10)
    try:
        with allure.step("Given: Authenticated user loads checkout page"):
            driver.get("http://staging-shop:8080/checkout")
            wait.until(lambda d: d.execute_script("return document.readyState") == "complete")
            
        with allure.step("When: User submits 20% discount coupon SPRING20"):
            promo_box = wait.until(EC.visibility_of_element_located((By.CSS_SELECTOR, "input[name='promo_code'], #promo")))
            promo_box.send_keys("SPRING20")
            driver.find_element(By.CSS_SELECTOR, "button[data-testid='btn-apply']").click()

        with allure.step("Then: Order total reflects exact 20% deduction"):
            total_badge = wait.until(EC.visibility_of_element_located((By.CSS_SELECTOR, "[data-testid='order-total']")))
            assert total_badge.text == "$80.00", f"Unexpected total: {total_badge.text}"
    finally:
        driver.quit()
